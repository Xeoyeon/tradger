# Tradger

외화와 원화를 함께 기록하고 보여주는 모바일(iOS/Android) 가계부.

- 지출을 외화(USD, JPY 등)와 원화로 동시에 표시
- 환전할 때의 환율을 입력하면 그 환율로, 없으면 현재 환율로 원화 환산
- 통화별 총액과 원화 환산 총액을 함께 제공
